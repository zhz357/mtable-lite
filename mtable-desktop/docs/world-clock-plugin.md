# 世界时钟插件（world-clock）安装与使用文档

> 所属平台：MTable 插件市场 · 插件标识 `world-clock` · 版本 v1.0.0 · 分类：工具 · 形态：菜单卡片（card）

显示全球主要国家与城市的实时时间：基于 IANA 时区数据库自动完成时区换算与夏令时切换，日期随城市实时同步，模拟表盘 + 数字双显示，支持城市搜索、收藏管理、12/24 小时制与多主题。

---

## 一、功能清单

### 1. 核心功能
- 内置 60 个全球主要城市（覆盖中国、日韩、东南亚、南亚、中东、欧洲、非洲、南北美洲、大洋洲）
- 时区自动转换：基于 `Intl` + IANA 时区数据库，夏令时（DST）自动生效，无需手动校准
- 日期同步：每张城市卡片显示该城市的本地日期与星期，跨日城市（如纽约比北京晚一天）正确标注
- 实时刷新：数字时间秒级刷新，表盘指针以 requestAnimationFrame 平滑走动（对齐系统时钟，无累积漂移）
- 昼夜标识：☀️ / 🌙 按城市当地时间 6:00–18:00 判定；本地时钟横幅随昼夜切换渐变底色
- 时区标签：每城显示 UTC 偏移（支持 UTC+5:30 等半小时时区）与"比本地 ±N 小时"差值

### 2. 交互功能
- 内置城市列表：点击搜索框即展开按国家分组的完整城市目录（国家标题吸顶、含 UTC 偏移），滚动浏览、点击即添加
- 城市搜索：顶栏搜索框支持中文名 / 英文名 / 国家 / 时区关键字，实时过滤定位（最多 12 条），回车添加首个结果
- 常用城市收藏：添加的城市即收藏列表，持久保存；已添加城市在搜索结果中标注"已添加"，点击可定位闪烁高亮
- 移除城市：悬停卡片右上角 × 按钮，带退场动画
- 时间格式：一键切换 24 小时制 / 12 小时制（AM/PM）
- 主题：跟随系统 / 浅色 / 深色三态循环切换；另有靛蓝 / 海洋 / 落日 / 森林四种强调配色

### 3. 界面与适配
- 顶部本地时钟横幅（大字号时间 + 日期 + 时区）+ 自适应城市卡片网格
- 响应式：宽屏多列，窄屏自动减列，≤420px 单列，搜索框自动换行
- 卡片入场 / 退场 / 悬停浮起动画；尊重系统"减弱动态效果"设置

## 二、安装说明

### 步骤 1：登记插件目录（数据库）
插件包内 `mtable-desktop/main/db.js` 的 `PRESET_PLUGINS` 已登记（应用启动时自动 `INSERT OR IGNORE`，可安全重复执行）：

```sql
INSERT IGNORE INTO t_plugin (plugin_key, name, description, icon, category, type, version, sort_order, is_enabled) VALUES
('world-clock', '世界时钟', '全球主要国家与城市实时时间：时区自动转换与日期同步，模拟+数字双显示、昼夜标识，支持城市搜索、常用城市收藏、12/24 小时制切换、多主题与响应式布局。', 'globe', '工具', 'card', '1.0.0', 7, 1);
```

### 步骤 2：插件资源文件
将插件包内 `world-clock/` 目录放入 `mtable-desktop/renderer/game/world-clock/`（桌面端已内置，随构建发布即可）：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 插件页面骨架（顶栏 / 本地时钟横幅 / 城市卡片网格 / 搜索下拉） |
| `style.css` | 插件样式（多主题变量、四色强调配色、响应式与动画） |
| `logic.js` | 纯时区逻辑（城市目录、IANA 换算、夏令时偏移、格式化、搜索），可独立单元测试 |
| `game.js` | 渲染与交互（表盘绘制、搜索收藏、主题格式切换、本地存储） |

页面通过 `game://world-clock/index.html` 加载，由 Electron 主进程 `game://` 协议映射到本地目录，与俄罗斯方块等游戏插件同一套加载机制。

### 步骤 3：在插件市场安装
1. 启动 MTable 桌面端并登录；
2. 点击左侧栏底部「插件」进入插件市场，在「工具」分类找到「世界时钟」卡片；
3. 点击「安装」，选择目标菜单（与游戏插件一致，卡片安装到所选菜单下）；
4. 打开目标菜单，点击「世界时钟」卡片即可使用。

卸载：插件市场中点击「卸载」，卡片随之移除；收藏城市与偏好保留在 localStorage，重新安装后恢复。

## 三、使用指引

| 操作 | 说明 |
| --- | --- |

## 四、配置项（localStorage）

存储键：`com.mtable.worldclock`

```json
{
  "cities": ["北京", "东京", "伦敦"],
  "hour12": false,
  "theme": "auto",
  "accent": "indigo"
}
```

| 配置项 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| `cities` | 城市中文名数组 | 10 个预置城市 | 收藏列表，按添加顺序展示 |
| `hour12` | `true` / `false` | `false` | 12 / 24 小时制 |
| `theme` | `auto` / `light` / `dark` | `auto` | 主题模式，`auto` 跟随系统 |
| `accent` | `indigo` / `ocean` / `sunset` / `forest` | `indigo` | 强调配色 |

数据损坏或以非法值启动时自动回退默认配置，不阻塞使用。

## 五、技术说明

- **时区换算**：`Intl.DateTimeFormat` 按 IANA 时区取城市墙钟时间，与 UTC 求差得到分钟级偏移，夏令时切换（如伦敦 BST/GMT）由时区数据库自动处理；
- **无漂移刷新**：每秒整秒对齐重算各城市时钟（含日期、偏移、昼夜），帧间仅按毫秒插值指针角度，休眠恢复 / 切回窗口立即校正；
- **逻辑与渲染分离**：`logic.js` 为 UMD 纯函数模块，已通过 40 项自动化断言（时区换算、DST、半小时时区、跨日日期、格式、搜索、指针角度）；
- **兼容性**：遵循插件市场 card 型规范（`t_plugin` 登记 + `game://` 加载 + 市场安装/卸载），与现有游戏插件同一集成路径，无额外依赖、不修改宿主代码。

## 六、常见问题（FAQ）

**Q：时间准确吗？需要联网校准吗？**
A：不需要。时间取自本机系统时钟，时区换算基于内置 IANA 数据库离线完成，与系统时钟保持同步。

**Q：为什么有的城市日期和我不一样？**
A：正常现象。地球存在国际日期变更线，如北京 15 日上午对应纽约 14 日晚，卡片日期按各城市当地显示。

**Q：卸载会丢收藏城市吗？**
A：不会。卸载只移除入口卡片，收藏与主题偏好保留在本地，重新安装自动恢复。
