# 俄罗斯方块插件（tetris）安装与使用文档

> 所属平台：MTable 插件市场 · 插件标识 `tetris` · 版本 v1.0.0 · 分类：游戏 · 形态：菜单卡片（card）

经典俄罗斯方块小游戏：方块随机生成、移动旋转、行消除、连消计分，支持简单 / 中等 / 困难三档难度，可暂停继续、重新开始，实时显示得分、等级与下一方块预览。

---

## 一、功能清单

### 1. 核心玩法
- 10×20 棋盘，7 种标准方块（I / O / T / S / Z / J / L），按"方块袋"随机生成（每袋内各方块恰好出现一次，避免长期缺块）
- 左右移动、顺 / 逆时针旋转（含踢墙修正）、软降、硬降
- 行消除（1~4 行同时消除），消行后上方自动下落补位
- 游戏结束判定：新方块出生点被占用即结束，弹出结算面板（得分 / 消行 / 最佳纪录）

### 2. 三档难度
| 难度 | 初始方块类型 | 下落间隔（Lv1） | 消行得分系数 |
| --- | --- | --- | --- |
| 简单 | I / O / T 共 3 种 | 800 ms | ×1 |
| 中等 | I / O / T / L / J 共 5 种 | 450 ms | ×2 |
| 困难 | 全部 7 种 | 220 ms | ×3 |

- 每消除 10 行升 1 级，下落间隔按 `间隔 × 0.85^(等级-1)` 加速，并按下限封底（简单 220 ms / 中等 120 ms / 困难 60 ms）

### 3. 计分规则
- 消 1 行 = 100、2 行 = 300、3 行 = 500、4 行 = 800，再乘以难度系数（×1 / ×2 / ×3）
- 软降每格 +1 分，硬降每格 +2 分
- 各难度分别记录最佳得分（localStorage），游戏结束时自动更新

### 4. 辅助功能
- 暂停 / 继续（P 键或顶栏按钮，暂停弹层显示当前战绩）
- 重新开始（R 键或 🔄 按钮）
- 实时得分、当前等级、消除行数、下一方块预览
- 难度一键切换，切换即重开新局

## 二、安装说明

### 步骤 1：登记插件目录（数据库）
执行插件包内 `plugin.sql`（或 `mtable-backend/src/main/resources/db/mtable.sql` 末尾的增量段落）：

```sql
INSERT IGNORE INTO t_plugin (plugin_key, name, description, icon, category, version, sort_order, is_enabled, type) VALUES
('tetris', '俄罗斯方块', '经典俄罗斯方块：简单/中等/困难三档难度，方块袋随机生成、旋转踢墙、行消除与连消计分，实时得分、等级、下一方块预览，支持暂停继续、重新开始与最佳纪录。', 'cube.fill', '游戏', '1.0.0', 6, 1, 'card');
```

> 该语句使用 `INSERT IGNORE`，可安全重复执行。

### 步骤 2：游戏资源文件
将插件包内 `tetris/` 目录放入 `mtable-desktop/renderer/game/tetris/`（桌面端已内置，随构建发布即可）：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 插件页面骨架（顶栏 / 棋盘 / 侧边面板 / 结算弹层） |
| `style.css` | 插件样式（与插件市场统一 UI 风格、自适应高度） |
| `logic.js` | 纯游戏逻辑（碰撞、旋转踢墙、消行、计分、难度参数），可独立单元测试 |
| `game.js` | 渲染与交互（Canvas 绘制、键盘操作、HUD、暂停 / 重开、最佳纪录） |

游戏页面通过 `game://tetris/index.html` 加载，由 Electron 主进程 `game://` 协议映射到 `renderer/game/tetris/` 本地目录。

### 步骤 3：在插件市场安装
1. 启动 MTable 桌面端并登录；
2. 点击左侧栏底部「插件」进入插件市场；
3. 找到「俄罗斯方块」卡片，选择目标菜单点击「安装」（安装为该菜单下的游戏卡片）；
4. 打开目标菜单，点击「俄罗斯方块」卡片即可开始游戏。

卸载：插件市场中点击「卸载」，卡片随之移除；本地最佳纪录保留，重新安装后恢复。

## 三、使用指引

### 操作方式
键盘与屏幕按钮双通道，鼠标 / 触屏可直接点按右侧按钮游玩（长按 ← → ↓ 连续移动）：

| 按键 | 屏幕按钮 | 操作 |
| --- | --- | --- |
| ← / → 或 A / D | ← / → | 左右移动 |
| ↑ / W / X | ↻ | 顺时针旋转 |
| Z | — | 逆时针旋转 |
| ↓ 或 S | ↓ | 软降（每格 +1 分） |
| 空格 | ⇊ | 硬降（每格 +2 分） |
| P / Esc | ⏸ | 暂停 / 继续 |
| R | 🔄 | 重新开始 |

### 界面区域
- 顶栏：难度切换（简单 / 中等 / 困难）、暂停、重新开始
- 左侧：棋盘（高度自适应窗口，尽量占满可用空间），暂停 / 结束时弹出浮层
- 右侧：下一方块预览、得分 / 等级 / 消除行数、当前难度与最佳纪录、屏幕操作按钮
- 底部：键盘操作提示

## 四、技术说明

### 随机与公平性
- 方块袋（7-bag 变体）：每袋把该难度允许的方块洗牌后依次发放，同袋内不重复，杜绝连续同块；
- 出生点水平居中，出生即检测碰撞，作为唯一游戏结束条件。

### 旋转与边界
- 旋转采用踢墙修正：依次尝试原位、±1、±2 水平偏移与上移 1 格，均被占用才拒绝旋转；
- 移动、旋转、下落全部先做碰撞检测（左右墙、底边、已占格），越界操作直接忽略，不会产生非法棋盘。

### 性能
- Canvas 绘制 10×20 棋盘，每帧仅重绘约 200 格，requestAnimationFrame 驱动，无定时器漂移；
- 逻辑层（logic.js）与渲染层分离，计分 / 消行 / 碰撞等纯函数经过自动化测试（16 项断言 + 3000 次随机操作模糊测试）；
- 视图销毁（切换菜单）后无后台占用；localStorage 读写均有异常保护。

### 本地数据存储
- 存储键：`mtable.tetris.best`（localStorage），结构：`{"easy": 12800, "medium": 5400, "hard": 900}`

## 五、常见问题（FAQ）

**Q：切换难度会丢进度吗？**
A：会。切换难度即按新难度重开新局，各难度最佳得分分别独立记录。

**Q：暂停后回来方块瞬移下落？**
A：不会。暂停期间计时归零，继续后从当前格重新累计下落时间。

**Q：删除插件会删掉最佳纪录吗？**
A：不会。卸载只移除卡片入口，最佳纪录保留在本地，重新安装后自动恢复。
