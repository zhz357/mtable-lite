# 倒计时插件（countdown）安装与使用文档

> 所属平台：MTable 插件市场 · 插件标识 `countdown` · 版本 v1.0.0 · 分类：工具

倒计时插件用于管理多个重要时刻：创建时只需填写**标题**与**目标日期时间**，插件会实时显示剩余的天、时、分、秒，到期后自动弹出视觉提示并播放提示音。

---

## 一、功能清单

### 1. 基础倒计时
- 自定义标题（最多 50 字）+ 日期时间选择器（精确到分钟的目标时间）
- 实时显示剩余 **天 / 时 / 分 / 秒**，秒级刷新
- 到期提醒：卡片高亮 + Toast 触觉提示 + 声音提醒（Web Audio 合成三声蜂鸣，可在顶栏一键开关）

### 2. 编辑与管理
- 新建 / 编辑 / 删除倒计时项目（编辑可修改标题、目标时间、分类、颜色、备注、提醒选项）
- 标记完成 / 恢复进行
- 数据本地保存与加载（localStorage，刷新、重启应用后不丢失）
- 排序：手动排序（上移 / 下移）/ 按剩余时间 / 按创建时间 / 按名称
- 分类管理：内置「学习 / 工作 / 生活 / 节日 / 其他」，支持新增、删除分类，顶部分类标签一键筛选

### 3. 界面与交互
- 卡片式布局，色彩标签（蓝 / 紫 / 绿 / 橙 / 红 五种卡片主题色）
- 深色 / 浅色模式一键切换（随偏好持久化）
- 响应式布局：宽屏多列、窄屏自动减列直至单列
- 空状态、加载与错误均有明确提示

### 4. 扩展功能
- 到期后自定义操作：仅提醒 / 提醒并自动标记完成
- 数据导入 / 导出（JSON 文件，可用于备份与迁移）

## 二、安装说明

### 步骤 1：登记插件目录（数据库）
插件需先出现在插件市场列表中。对 `mtable` 库执行 `mtable-backend/src/main/resources/db/mtable.sql` 文件末尾的增量段落（如库已初始化到 V11 之后，只需执行新增的增量）：

```sql
INSERT IGNORE INTO t_plugin (plugin_key, name, description, icon, category, version, sort_order, is_enabled) VALUES
('countdown', '倒计时', '创建多个倒计时，实时显示剩余天/时/分/秒，到期视觉与声音提醒，支持分类管理、排序、深浅色主题与数据导入导出。', 'timer', '工具', '1.0.0', 1, 1);
```

> 该语句使用 `INSERT IGNORE`，可安全重复执行。

### 步骤 2：前端文件（已随桌面端源码内置）
本插件为桌面端内置渲染视图，涉及以下文件，随 `mtable-desktop` 一起构建发布即可：

| 文件 | 作用 |
| --- | --- |
| `mtable-desktop/renderer/js/views/countdown.js` | 插件视图（核心逻辑） |
| `mtable-desktop/renderer/css/countdown.css` | 插件样式（含深浅色主题、响应式） |
| `mtable-desktop/renderer/js/views/main.js` | 插件路由注册（`pluginContent` 中 `countdown` 分支） |
| `mtable-desktop/renderer/index.html` | 引入 `css/countdown.css` |

### 步骤 3：在插件市场安装
1. 启动 MTable 桌面端并登录；
2. 点击左侧栏底部「插件」进入插件市场；
3. 找到「倒计时」卡片，点击「安装」；
4. 安装成功后侧边栏出现「倒计时」菜单，点击即可使用。

卸载：插件市场中点击「卸载」，侧边栏菜单随之移除；本地倒计时数据保留在 localStorage 中，重新安装后自动恢复。

## 三、使用指引

### 新建倒计时
1. 点击右上角「+ 新建倒计时」；
2. 填写标题、选择目标日期时间（必填），可选：分类、卡片颜色、备注、到期后操作、是否到期提醒；
3. 点击「创建」，卡片立即出现在列表中并开始倒计时。

### 编辑 / 删除 / 完成
- 卡片右上角「铅笔」图标 → 编辑；「垃圾桶」图标 → 删除（有二次确认）；
- 卡片右下角「标记完成」/「恢复进行」切换状态；
- 目标时间被改到未来时，到期提醒会自动重置，可再次触发。

### 排序与分类
- 工具栏「排序」下拉：手动排序 / 按剩余时间 / 按创建时间 / 按名称；
- 手动排序模式下，卡片右下角出现「↑ / ↓」按钮调整顺序；
- 工具栏分类标签可筛选；「⚙ 分类」可新增 / 删除分类（删除分类时其下倒计时自动归入其他分类）。

### 主题与提醒
- 右上角「太阳 / 月亮」图标切换浅色 / 深色模式；
- 「铃铛」图标开关到期提示音；
- 系统静音环境下提示音自动静默失败，不影响其他功能。

### 导入 / 导出
- 右上角「上传」图标导出 JSON 备份文件，「托盘」图标导入；
- 导入为合并模式：已存在 ID 自动重新生成，不会覆盖现有数据；文件格式非法时给出错误提示。

## 四、技术说明

### 时间计算准确性
- 目标时间以 **Unix 毫秒时间戳**存储，剩余量每次刷新都用 `Date.now()` 现算，不依赖定时器累加，无累积误差；
- 刷新定时器对齐到「下一整秒」触发，避免 `setInterval` 漂移；
- 系统时间被修改后，下一次刷新自动按新时钟校正显示；切回窗口/从休眠恢复后同样自动纠正；
- 到期判定使用同一时间戳比较，每次到期只触发一次提醒（`notified` 标记随数据持久化）。

### 本地数据存储
- 存储键：`com.mtable.countdowns`（localStorage），结构：

```json
{
  "version": 1,
  "settings": { "theme": "light", "soundOn": true, "sortBy": "manual" },
  "categories": ["学习", "工作", "生活", "节日", "其他"],
  "items": [
    {
      "id": "cd-xxxx", "title": "期末考试", "targetTime": 1793337600000,
      "category": "学习", "accent": "blue", "note": "",
      "remindAtEnd": true, "endAction": "notify",
      "createdAt": 1791531600000, "sortOrder": 0,
      "notified": false, "done": false
    }
  ]
}
```

### 性能与错误处理
- 每秒刷新只更新 4 个数字节点与进度条宽度，不整卡重排；列表变化时才整体重渲染；
- 视图销毁（切换菜单）后定时器自动停止，无后台资源占用；
- 本地存储读写、JSON 导入、文件导出均有 try/catch 保护，失败时 Toast 提示，数据损坏时以空数据启动并提示，不阻塞应用。

### 平台兼容
- 遵循插件市场开发规范：`t_plugin` 目录登记 + `plugin_key` 路由渲染，与「学习路线」等现有插件同一套安装/卸载流程；
- 使用桌面端统一设计变量（`--primary`、`--text-1` 等）与组件风格，适配最新版本插件市场平台。

## 五、常见问题（FAQ）

**Q：刷新或重启后数据会丢吗？**
A：不会。所有倒计时保存在本地 localStorage，自动加载。如需换机迁移，使用导出 / 导入功能。

**Q：到期了但没有声音？**
A：请确认顶栏铃铛处于开启状态；部分系统在静音或未与页面交互过的情况下会拦截音频，属浏览器安全策略，插件会静默降级，视觉提醒不受影响。

**Q：删除插件会删掉我的倒计时吗？**
A：不会。卸载只是移除侧边栏入口，数据保留；重新安装即可恢复使用。
